# LUMÉA — Candle Store

A modern, elegant candle-store website concept built for handmade and scented candle brands.

## About

LUMÉA is a frontend website concept designed to demonstrate how a candle brand can showcase its products online and provide a simple WhatsApp-based ordering experience.

This is currently a **demo concept**. Additional pages and features can be added and customized for a specific candle brand.

## Current Features

- Responsive landing page
- Product showcase
- Modern candle-focused design
- WhatsApp-based ordering flow
- Cart functionality
- Responsive layout for desktop and mobile

## Planned Pages

- Shop
- Product Details
- About
- Contact
- Checkout / WhatsApp Order

## Tech Stack

- React
- Tailwind CSS
- JavaScript
